# Livraria Entrelinhas

Bem-vindo à **Livraria Entrelinhas** — um espaço online para amantes da leitura descobrirem novos mundos através dos livros.

## Sobre o projeto
A **Entrelinhas** é uma livraria virtual que oferece uma seleção cuidadosa de obras para todos os gostos e interesses.  
O site foi desenvolvido para proporcionar uma experiência agradável, elegante e intuitiva, conectando leitores a histórias que inspiram e transformam.

## Funcionalidades
- Página inicial com destaque para livros selecionados
- Catálogo organizado por categorias e gêneros
- Detalhes de cada obra com capa, título, autor e descrição
- Layout responsivo para dispositivos móveis e desktop

## Tecnologias utilizadas
- **HTML5**
- **CSS3**
- **JavaScript**

## Objetivo
Oferecer uma experiência de compra e descoberta literária simples, bonita e funcional, valorizando o design e a usabilidade.
